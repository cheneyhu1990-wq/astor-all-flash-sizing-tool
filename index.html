Capacity formula (matches the official Excel tool exactly):
Usable (TiB) = ( Raw(TB) × 931⁄1024 × 0.9 − 0.352 ) × N ⁄ (N+2), where EC = N+2 and 0.352 TiB is reserved for the arbitration/quorum partition.
1 TB (decimal, disk-rated) ≈ 0.91 TiB (binary, OS-visible). Minimum disks per EC ratio = N+4 (2 parity + 2 hot-spare reserve).

3 Cache Disk Sizing & File-Count Capacity Check (QLC models only)

F3000Q/F6000Q require a minimum of 4 TLC cache disks per chassis (5+ recommended for higher availability — with only 4, a second cache-disk failure halts all file services). 15.36TB data disks must pair with 3.84TB cache disks; 30.72TB data disks must pair with 7.68TB cache disks. Cache + data disk count must not exceed 24 slots per chassis.
